# Contribuições

Este SDK é desenvolvido e mantido exclusivamente pela Ferrazio, única detentora
do código. **Não aceitamos pull requests, patches nem contribuições de código**, e
pull requests abertos por terceiros são fechados sem revisão.

## Como você pode participar

- **Bug:** abra uma issue com o modelo "Bug".
- **Sugestão de melhoria:** abra uma issue com o modelo "Sugestão".
- **Dúvidas e conversas gerais:** use as **Discussions** do repositório.
- **Vulnerabilidade:** nunca em público. Siga o [SECURITY.md](SECURITY.md).

Em qualquer caso, não publique chaves de API, tokens ou dados reais. Toda
participação segue o [Código de Conduta](CODE_OF_CONDUCT.md).
